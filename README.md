## About The Project

![WarQ ScreenShot][WarQ-screenshot]

An angel investor platform is a valuable web tool for providing funding to startups with high potential that may not have access to traditional financing. Our platform seeks to form investment syndicates to encourage a wide range of investors to support startups. With our platform, angel investors and startups can conveniently connect and collaborate. Our goal is to make angel investing accessible and to promote investment in startups for innovation and growth.

Here's why:
* Focus on creating a solution that adds value and solves real-world problems.
* Aim to bridge the communication gap and connect investors with startups.
* Attracting potential investors can be a complex process for startups.
* Avoid repetitive tasks by using a well-structured web.

## Getting Started

To get a local copy up and running, follow these simple example steps.

### Prerequisites

You will need to have npm and Python installed on your system.

* npm
  ```sh
  npm install npm@latest -g
    ```

* Python
    ```sh
    sudo apt-get install python3
    ```

### Installation

1. Clone the repo

    ```sh
        git clone https://github.com/AngelInvestorsPlatform/Angel-Investors-Platform.git
    ```

2. Install packages from requirements.txt


3. Install NPM packages
    ```sh
        cd frontend
        npm install
        npm start
    ```

4. set up the PostgreSQL Database

5. Set up the Django backend
    ```sh
        cd backend
        python manage.py makemigrations
        python manage.py migrate
        python manage.py runserver
    ```
